# Proyecto_pythonpro.MartesM10l1
proyecto final:

Mi proyecto final es una página web creada para concienciar a las personas sobre la contaminación,
el cambio climático y la deforestación. La idea es que, al entrar, cada usuario pueda explorar tres secciones diferentes:
la primera hablará sobre los tipos de contaminación, sus causas y consecuencias; la segunda explicará qué es el cambio climático,
sus efectos y qué podemos hacer para ayudar; y la tercera mostrará cómo la deforestación afecta al planeta,
las especies y a las comunidades, incluyendo estadísticas, relatos de personas afectadas y videos que ayuden a entender mejor cada tema.

La página funcionará de manera muy intuitiva: habrá un menú principal con las tres secciones, y al hacer clic en cualquiera,
se abrirá la información sin recargar toda la página, haciendo la experiencia más fluida y agradable.
En cada sección, los usuarios podrán leer textos claros, ver imágenes, gráficos y videos,
consultar datos y estadísticas reales, y conocer historias de personas afectadas.
También habrá botones para navegar fácilmente entre las secciones y volver al menú principal.

Para que todo sea visualmente atractivo, 
usaré HTML para la estructura y CSS para los estilos,
con una paleta de colores pensada para cada tema: azules y verdes para la contaminación,
amarillos y naranjas para el cambio climático, y verdes intensos y beige para la deforestación.
La tipografía será clara y los elementos estarán organizados para que todo sea fácil de entender.
La meta no es solo informar, sino también despertar conciencia y motivar a que cada persona tome acción para cuidar nuestro planeta.
